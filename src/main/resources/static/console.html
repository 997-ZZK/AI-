3.3 一次性音频（ASR / TTS）


音频只在本次请求与当前页面内存中处理，不进入会话、附件、事件或浏览器存储。mock ASR 是固定模拟转写，mock TTS 是静音 WAV，仅用于联调。


客户端上传上限 5MiB、合成文本上限 2000 个 Unicode 码点；文件格式、时长及服务端有效限制以 API 校验为准。
