# 运维手册 · 故障处理

## 检索报 503：向量来源不一致
现象：接口返回「知识库 X 的向量由 [旧模型] 生成，与当前 embedding provider 不在同一向量空间」。
原因：换过 embedding 模型，但索引还是旧模型算的。向量只在同一模型的向量空间里可比，
拿旧向量算余弦会得到看起来正常但毫无意义的分数，因此系统选择显式失败。
处理：调用 POST /api/v1/kbs/{kbId}/reindex 用当前模型重建索引。

## 能力矩阵显示某档 down
先看 detail 字段，它写的是具体原因而不是笼统的失败：
「探活失败: ConnectException」说明服务没起；「端点在线但模型列表中不含 X」说明服务起了但模型没拉。

## 额度硬上限
返回预设话术并把 run 标记为 DEGRADED，不是 500。用 GET /api/v1/budget/users/{userId} 查看用量与重置时刻。

## SSE 断流
客户端断线属正常现象，日志里是 debug 级别。重连时带上 Last-Event-ID 即可从断点续传，不会重复终态。

## Redis 不可用
会话锁关闭时不受影响；开启锁时快速失败并给出提示，不会静默降级成无锁。
