# AIFlow 引擎 · 产品手册

## 它是什么
AIFlow 是一个工作流引擎：把 LLM 调用、工具调用、条件分支、人工审批编排成有向无环图（DAG），
每次执行都落库留痕，可通过 SSE 观察执行过程。它不是聊天框，而是「让模型干活」的编排层。

## 节点类型
- start / end：入口与出口
- llm.chat：文本对话，支持模板变量
- llm.vision：图片问答，需要同时具备 chat 与 vision 能力的档位
- retrieval.search：知识库检索，输出带引用的上下文块
- tool.call：HTTP 工具调用，默认关闭
- condition：条件分支，使用 SpEL 表达式
- delay：延时节点，供压测与超时演练

## 分级路由
档位顺序由配置声明，默认 local -> cloud -> mock。本地档负责断网兜底，云端档负责加速与复杂任务，
mock 只兜住流程本身。探活每隔 15 秒检查一次端点，除了服务是否存活，还会核对模型清单里有没有配置的模型名。

## 检索阈值
检索阈值（min-score）跟着向量模型走：mock 量纲校准值是 0.35，真实模型 bge-m3 的校准值是 0.55。
阈值过低会把不相关切片放进提示词，过高会让可答问题召回为空。

## 每用户额度
按自然日结算，软阈值触发后优先使用便宜档位，硬上限触发后直接返回预设话术而不是报错。
